Hotel Reservation System

Project Description

Hotel Reservation System is a console-based Java application designed to manage hotel room bookings. It allows users to view room types, check room availability, book rooms, view booking details, and cancel reservations.

The system provides different room categories with different prices and facilities. It also stores booking information in a text file for record keeping.

Features

- Display different room types and their facilities
- View available rooms and their rent
- Book hotel rooms
- View booking details using a mobile number
- Cancel room reservations
- Automatically update room availability
- Save booking records in a text file

Room Categories

- Lower Room: ₹1,200 — Single bed, AC
- Medium Room: ₹2,000 — Double bed, AC
- Standard Room: ₹3,000 — Double bed, AC, TV

Technologies Used

- Java
- ArrayList
- Scanner
- File Handling (FileWriter)
- Object-Oriented Programming (OOP)

How to Run

1. Install Java JDK.

2. Download or clone this repository.

3. Open the project in VS Code.

4. Compile the Java file:
   
   "javac hotelReservation.java"

5. Run the program:
   
   "java hotelReservation"
